# 撰寫語法（render.mjs 支援的 Markdown）

標準 GitHub Markdown（標題、清單、表格、粗體、程式碼區塊）全部可用，另外加上以下擴充。

## Front matter（每份文件開頭）

```markdown
---
title: 線性代數 期中考 重點整理
subtitle: Ch1–Ch4 · 線性系統、矩陣、行列式、向量空間
course: 線性代數 CE2005
kind: notes            # handout | notes | patterns | cornell | layered | practice | answers | cheatsheet
exam_date: 2026-11-05  # 可省略；有填會顯示「距考試 N 天」
---
```

`kind` 決定頁首橫幅的標籤與配色。整理類文件（handout、notes、patterns、cornell、layered）有 4 個以上 `##` 章節時自動產生目錄；`toc: true`／`toc: false` 可強制開關。

## 標題層級

- `##` 章節（會進目錄）、`###` 小節、`####` 細項
- **不要手動編號**（不要寫 `## 1. 線性系統`）：教科書主題會自動加編號，手寫會重複
- 不要用 `#`，頁首橫幅已經是 h1

## 數學

KaTeX 渲染，語法同 LaTeX：

- 行內：`$\det A \neq 0$` 或 `\(...\)`
- 獨立一行：`$$ ... $$` 或 `\[ ... \]`
- 多行對齊用 `\begin{aligned} ... \end{aligned}`；長公式務必拆行，避免超出頁寬
- 增廣矩陣：`\left[\begin{array}{cc|c} 1 & 2 & 3 \\ 4 & 5 & 6 \end{array}\right]`
- 金額的 `$` 請寫成 `\$`，否則會被當成公式

## 重點框 `:::類型 標題` … `:::`

```markdown
:::def 線性獨立 (Linear Independence)
若 $c_1\mathbf v_1+\dots+c_k\mathbf v_k=\mathbf 0$ 只有零解，則稱向量組線性獨立。
:::
```

| 類型 | 標籤 | 用途 |
|---|---|---|
| `def` | 定義 | 名詞定義 |
| `thm` | 定理 | 定理、性質、等價條件 |
| `formula` | 公式 | 需要背的公式 |
| `example` | 例題 | 小例子／範例計算 |
| `warn` | 易錯 | 學生常犯的錯誤 |
| `hot` | 常考 | 考古題反覆出現的重點 |
| `tip` | 技巧 | 解題技巧、記憶法 |
| `extra` | 補充 | **資料以外**補充的內容（虛線框） |
| `summary` | 本章摘要 | 每章開頭的概述 |
| `past` | 考古題分析 | 出題分布、命題趨勢 |

- 標題可省略；框內可以放任何 Markdown（清單、公式、表格）
- 框可以巢狀，但盡量不要超過兩層
- `:::` 開頭與結尾都要獨立成一行

## 徽章 `{{...}}`

放在句子或標題中：`行列式性質 {{常考}}`

| 寫法 | 樣式 |
|---|---|
| `{{常考}}` `{{必考}}` | 橘色 |
| `{{補充}}` | 灰色虛線（資料以外的內容） |
| `{{易錯}}` | 紅色 |
| `{{考古題}}` | 紫色 |
| `{{已驗算}}` | 綠色「✓ 已驗算」 |
| `{{無法程式驗算}}` | 黃色 |
| `{{難度: ★★☆}}` | 星等 |

## 題目卡 `:::q` 與解答卡 `:::a`

標頭用 `|` 分隔：`題號 | 標籤… | space=N`

```markdown
:::q 3 | 計算題 | ★★☆ | space=6
求 $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 的特徵值與特徵向量。
:::

:::q 4 | 選擇題 | ★☆☆ | 考古題改編
下列何者**不是**可逆矩陣的等價條件？

(A) $\det A\neq 0$　(B) $\operatorname{rank}A=n$　(C) $A$ 為對稱矩陣　(D) $A\mathbf x=\mathbf 0$ 只有零解
:::
```

- 題號寫在最前面；省略則自動遞增
- 星等 `★☆☆` 基礎、`★★☆` 中等、`★★★` 挑戰
- `space=N`：在練習題下方畫 N 行作答線（計算題 4–8、證明題 6–10；選擇是非題不用）
- 其他標籤（題型、`考古題改編`、`補充`）會自動變成對應顏色的徽章
- 選擇題選項短的話放同一行用全形空白分隔；長的話每個選項一行，用空行分開

解答卡：

```markdown
:::a 3 | ✓ 已驗算
**思路**：特徵值滿足 $\det(A-\lambda I)=0$。

$$\det\begin{pmatrix}2-\lambda&1\\1&2-\lambda\end{pmatrix}=(2-\lambda)^2-1=0 \Rightarrow \lambda=1,3$$

**答**：$\lambda_1=1$，$\mathbf v_1=(1,-1)^T$；$\lambda_2=3$，$\mathbf v_2=(1,1)^T$。
:::
```

驗算狀態標籤：`✓ 已驗算` 或 `無法程式驗算`。

**中英對照題**：中文題幹後，用 `>` 開頭的段落寫英文翻譯，會以較小的灰色字顯示在中文下方。公式不用重複，英文句子可以直接引用同樣的符號。

```markdown
:::q 4 | 計算題 | ★☆☆ | space=6
求 $A=\begin{pmatrix}5&-1\\2&2\end{pmatrix}$ 的特徵值，以及每個特徵空間的一組基底。

> Find the eigenvalues and a basis for each eigenspace of $A$.
:::
```

選擇題的選項不用翻譯（選項多為公式或數字）；選項是文字時，把英文放在同一個 `>` 段落裡。

## 其他

- 分頁：獨立一行寫 `<!-- pagebreak -->`
- 雙欄區塊：`:::cols` … `:::`（適合短清單並排）
- 程式碼題：用 ```` ```c ```` 等 fenced code block
- 練習題文件建議依題型分 `##` 區段（例：`## 選擇題`、`## 計算題`），解答文件用同樣的區段

## 整理方式專用容器

各容器的寫法與用途詳見 `organize-styles.md`（地圖）與 `styles/*.md`（各整理方式），這裡只列語法。

| 容器 | 用途 |
|---|---|
| `:::map 標題` | 概念地圖外框（自動加圖例），內放 ```` ```mermaid ```` 區塊與一句閱讀提示 |
| `:::fig 圖說` | 圖片或 Mermaid 圖，自動編號「圖 N」 |
| `:::pattern 題型名 \| 考古題 3/4 年 \| 必考 \| ★★☆` | 題型解題卡；內部用 `####` 分段（辨識、SOP、範例、變形） |
| `:::cornell 主題` | Cornell 表格外框，內含多個 `:::cue` 與一個 `:::recap` |
| `:::cue 提示問題` | Cornell 的一列：標頭是左欄問題，內容是右欄答案 |
| `:::recap` | Cornell 底部的一句話總結 |
| `:::layer 1｜2｜3 [\| 說明]` | 分層講義的層級區塊（1 = 30 秒、2 = 5 分鐘、3 = 完整） |

**徽章補充**：`{{前置: 秩、零空間}}`（灰色虛線，標出需要先懂的概念）、`{{⏱ 5 分鐘}}`（時間標籤）。

**Mermaid**：在任何地方用 ```` ```mermaid ```` 都會被渲染成圖。`flowchart`／`graph` 會自動帶入節點類別 `def` `thm` `formula` `method` `hot` `pre`（寫法 `A["文字"]:::def`）。節點文字不能用 LaTeX，請用 Unicode 符號（λ、⁻¹、ᵏ、σ²、x̄、≤）。

**圖片**：`![](figs/xxx.svg)` 的相對路徑以 Markdown 檔所在資料夾為準。圖表產生方式見 `figures.md`。
