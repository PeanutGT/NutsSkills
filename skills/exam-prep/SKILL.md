# Exam Prep — 學習講義與考試複習包產生器

把使用者的學習資料**重新組織**成「印出來就能讀、寫、對答案」的 PDF。

這個 skill 的特色不是把教材照章節重寫一遍，而是：
1. **先做概念分析**：找出每個概念的前置依賴、出處、考古題出現次數與題型
2. **依使用者的需求重組知識**：照依賴順序學、照考試題型練、用主動回憶背、依剩餘時間分層讀
3. **每份整理文件都有概念地圖**，並且**能畫圖的就畫圖**
4. **數字全部用程式驗算**

## 可產出的文件

**整理文件**（可複選，每種一份 PDF；內容共用同一份概念分析，彼此一致）

| 整理方式 | kind | 檔名 | 回答的問題 |
|---|---|---|---|
| 章節講義（詳盡） | `handout` | `<科目>_學習講義.pdf` | 這個範圍到底在講什麼？（第一次學、沒聽懂時從頭讀） |
| 章節重點（精簡） | `notes` | `<科目>_重點整理.pdf` | 哪些東西要記？（學過了，考前回顧） |
| 題型解題卡 | `patterns` | `<科目>_題型解題卡.pdf` | 考試會怎麼問、看到題目該怎麼解？ |
| Cornell 回憶筆記 | `cornell` | `<科目>_回憶筆記.pdf` | 我真的記得嗎？（遮住右欄自我測驗） |
| 分層講義 | `layered` | `<科目>_分層講義.pdf` | 只有 30 秒／5 分鐘／充足時間，各該讀什麼？ |

**其他文件**

| 文件 | kind | 內容 |
|---|---|---|
| `<科目>_練習題.pdf` | `practice` | 題目卡，含題型、難度、作答空白 |
| `<科目>_解答.pdf` | `answers` | 逐題解答與思路，計算題標「✓ 已驗算」（和練習題分開，寫題時不會偷看到答案） |
| `<科目>_公式小抄.pdf` | `cheatsheet` | 雙欄高密度，一頁看完 |

語言：整理文件與公式小抄以繁體中文為主，**術語第一次出現時中英並列**，例如「特徵值 (eigenvalue)」。練習題與解答的語言由使用者選（見第 2 步），規則見 `references/question-design.md` 的「語言」一節。

## 工作流程

### 1. 先讀完所有資料

讀法依資料類型見 `references/reading-inputs.md`（投影片、PPT、掃描/手寫照片、考古題、**Google Drive 連結或資料夾**各有不同處理）。使用者提到 Drive、貼了 `drive.google.com`／`docs.google.com` 連結，或說「在我雲端的某資料夾」時，用 Google Drive 連接器讀取；沒有連接器就建議連接，或請他直接上傳。

先讀完再問問題，因為「範圍」的選項應該是資料裡真的有的章節。

### 2. 執行時詢問

用 AskUserQuestion，每輪最多 4 題。**使用者訊息裡已經講清楚的項目就跳過**；只問和這次產出有關的題目，題目超過 4 題就分到下一輪。使用者說「整理教材」「做成講義」「我沒聽懂，幫我從頭整理」，等於已選章節講義；說「題型」「解題技巧」等於已選題型解題卡。

**第一輪**
1. **範圍** — 選項用資料中的實際章節名（可複選），外加「全部」
2. **整理方式**（可複選）— 章節式（講義或重點）／題型解題卡／Cornell 回憶筆記／分層講義。說明欄各用一句話寫出適合誰（見上表）。有考古題時把題型解題卡標為推薦
3. **其他文件**（可複選）— 練習題＋解答／公式小抄／都不需要
4. **主題風格** — 現代筆記風 `modern`（推薦）／教科書風 `textbook`／精簡小抄風 `cheatsheet`（說明欄註明：小抄風只套用在公式小抄，其他文件選它時改用教科書風）

**第二輪**（只問相關的）
5. **章節式的詳細程度**（選了章節式才問）— 詳盡學習講義／精簡重點整理／兩份都要
6. **考古題用法**（有考古題才問，可複選）— 標出常考／練習題模仿考古題題型與難度／逐題詳解考古題本身
7. **題型與題數**（要練習題才問）— 例如「混合 15 題（推薦）」、「選擇/是非為主 20 題」、「計算＋證明為主 10 題」；理工科才提供證明題、計算題選項
8. **難度與考試日期** — 難度：基礎／混合（推薦）／挑戰；日期請使用者用 Other 填寫或選「不確定」
9. **練習題語言**（要練習題才問）— **跟考古題一樣**（有考古題時推薦，說明欄寫出考古題實際用的語言）／**中文**（術語中英並列）／**英文**／**中英對照**（中文題幹下附英文）。沒有考古題時，第一個選項改成和講義相同的語言

**沒人可問時的預設值**（排程執行或使用者不回應）：範圍＝全部；整理方式＝章節重點，有考古題時再加題型解題卡（使用者明顯是要學習/整理教材時，章節重點改為學習講義）；其他文件＝練習題＋解答；主題＝`modern`；混合題型 12–15 題；難度混合（4：4：2）；考古題兩種用法都做；練習題語言＝跟考古題一樣（沒有就用中文）。在回覆開頭用一句話說明採用了哪些預設。

**考試日期會改變寫法**：
- ≤ 3 天：重點整理精簡、優先常考，主動建議加做公式小抄或分層講義。若使用者選了學習講義，照做，但在回覆中提一句「時間緊的話可以先讀第一、二層／重點整理」
- 4–13 天：標準深度
- ≥ 14 天：可以多寫推導、觀念連結與延伸

### 3. 概念分析（所有整理文件的共同基礎，不可省略）

寫任何文件前，先在工作目錄寫一份 `concepts.md`（不交付）：每個概念的類型（定義/定理/公式/方法）、**前置概念**、出處、考古題出現次數、在考試中以什麼題型出現。格式與用法見 `references/organize-styles.md` 第 1 節。

這份表決定：
- **講解順序**：每個概念排在它的前置之後。教材順序與依賴順序衝突時以依賴順序為準，並在文中說明為什麼先講
- **概念地圖**的節點與箭頭
- **前置徽章** `{{前置: 秩、零空間}}`：讀者卡住時知道要回頭補什麼
- **常考**標記與題型解題卡的分組
- **畫哪些圖**：每個概念問「這個東西有形狀、有分布、有流程、有空間關係嗎？」有就記下要畫什麼圖

寫完文件後，對照 `concepts.md` 逐項檢查有沒有概念被漏掉。

### 4. 寫整理文件

所有 Markdown 都按照 `references/markdown-format.md` 的語法撰寫（數學公式、重點框、徽章、題目卡、地圖、圖片、解題卡、Cornell、分層容器）。**寫之前先讀它。**

**每一份整理文件都必須有：**
- **概念地圖**：第一個 `##` 之前一張全範圍總圖，每個 `##` 章開頭一張章節圖（`:::map` + Mermaid）。規格見 `references/organize-styles.md` 第 2 節
- **圖表**：能用圖說明的就畫圖，統計科目尤其要多。用 `scripts/figures.py` 產生 SVG，放進 `:::fig`。各種內容該畫什麼圖、怎麼畫，見 `references/figures.md`
- **來源規則**：內容以使用者資料為主。資料沒有但對理解或解題必要的內容可以補充，**必須**放進 `:::extra` 或加 `{{補充}}`
- 標題不要手動編號（教科書主題會自動編號）

各整理方式的寫法：
- **題型解題卡、Cornell 回憶筆記、分層講義** → `references/organize-styles.md` 第 3–5 節
- **章節講義** → 下面 4a
- **章節重點** → 下面 4b

同時產出多份整理文件時，用同樣的符號、同樣的例子；練習題不要和講義例題、自我檢測題、解題卡範例重複。

#### 4a. 章節講義（`handout`）

目標：一個**沒去上課**的同學，只讀這份講義就能把這個範圍學會。不能只列重點——每個觀念都要交代「是什麼、為什麼、怎麼用、哪裡會錯」。

**整合所有資料，不要丟內容**
- **投影片／上課講義**決定符號和用語（考試用的就是老師的版本）
- **課本**補足投影片省略的推導、條件和例子
- **手寫筆記**代表老師上課特別強調或口頭補充的內容，用 `:::hot 老師上課強調` 標出
- **考古題**用來標 `{{常考}}`，也可改編成例題；**作業**可作為例題或自我檢測題
- 不同資料的符號不一致時，以投影片為準，並用一句話註明另一種寫法

**每一章**
1. `## 章名`、章節概念地圖，接著不帶標題的 `:::summary`：2–3 句說明這章要解決什麼問題，再接「**學完本章你應該能夠：**」加 3–5 條可檢驗的學習目標
2. 依概念（照依賴順序）分 `###` 小節，每個概念依序寫：**動機**（為什麼需要它）→ **定義** `:::def` → **直觀理解** `:::tip 直觀理解`，**盡量配一張圖** → **定理** `:::thm 定理 5.2　名稱`，框內接證明（短證明寫完整，長證明寫概要；自己補的加 `{{補充}}`）→ **完整例題** `:::example`，每一步都寫並說明為什麼 → **常見錯誤** `:::warn` → **前置與連結**：`{{前置: …}}` 加一兩句和其他概念的關係
3. `### 本章重點回顧`：條列本章最重要的結論
4. `### 隨堂自我檢測`：3–5 題 `:::q`，以觀念題與簡單計算為主（不需作答空白）

**講義最後**：`<!-- pagebreak -->` 後接 `## 自我檢測解答`（`:::a`，同樣驗算）；有考古題時再加 `## 考古題分析`（`:::past`）。題號全份連續編號（渲染器只接受整數題號）。

**格式**：front matter `kind: handout`、`toc: true`，**不要填 `course`**，科目名稱放進 `subtitle`；每個 `##` 之前（第一章除外）加 `<!-- pagebreak -->`；用完整段落解釋，條列只用在回顧。篇幅參考：一堂課（2–3 小時）的教材約 6–12 頁。

#### 4b. 章節重點（`notes`）

不是把講義濃縮，而是**幫使用者決定什麼值得記**：
- 每章：章節概念地圖 → `:::summary`（3–5 句）→ 定義、定理、公式各用對應的框
- 每個重要觀念配一個小例子或一張小圖
- `:::warn` 寫學生實際會犯的錯，不寫泛泛提醒
- 有考古題時常考概念加 `{{常考}}`，最後一章用 `:::past` 做出題分布分析

### 5. 出練習題與解答

詳細原則見 `references/question-design.md`。重點：
- 題目涵蓋所選範圍，分配依「概念重要性 × 常考程度」；有題型解題卡時，每種題型至少一題，並在題目標籤寫出對應題型
- 題號在練習題與解答兩份文件中一致；計算題、證明題加作答空白 `space=N`
- 解答先寫**思路**（用哪個觀念、為什麼），再算；統計題的解答可以附圖（例如標出拒絕域）

### 6. 驗算（不可省略）

模型心算會出錯，錯的解答會讓使用者白練、甚至學錯。

```bash
pip install --break-system-packages -q sympy numpy scipy matplotlib 2>/dev/null
```

比較答案的工具在 `scripts/verify_helpers.py`（`check`、`is_eigvec`、`summary`），流程與範本見 `references/verification.md`。原則：
- 每題寫一小段程式重算，結果不符時**修正解答**（或修題目），不要硬湊
- 通過驗算的解答標 `✓ 已驗算`；證明、申論、概念說明等標 `無法程式驗算`，並寫出關鍵檢查點
- 選擇題要確認恰好一個選項正確（化簡後相等的選項很容易不小心出現兩個正解）
- **整理文件裡的數字也要驗**：例題結果、圖上標的數值（機率、平均、迴歸係數）、考古題配分統計、「每年都考」這類說法

### 7. 渲染 PDF

```bash
node <skill-dir>/scripts/render.mjs patterns.md 線性代數_題型解題卡.pdf --theme modern
```

- `--theme`：`modern` | `textbook` | `cheatsheet`（公式小抄一律用 `cheatsheet`；其他文件用使用者選的主題，選了 `cheatsheet` 則改用 `textbook`）
- 腳本會自動安裝缺少的 npm 套件（katex、marked、playwright、mermaid）到 `~/.exam-prep-deps`；環境已有全域安裝時先設 `NODE_PATH` 指向它
- 終端機出現 `mermaid error` 代表某張地圖語法錯誤（常見原因：節點文字含未加引號的括號或特殊符號、用了 LaTeX），修正後重新渲染
- 加 `--html out.html` 可保留中間 HTML 方便除錯

### 8. 檢查排版，再交付

渲染後**實際看**：`pdftoppm -r 60 -png file.pdf preview` 轉成圖片，至少檢視第 1 頁（含總圖）、一張章節圖、圖表最多的一頁、題目最密集的一頁。常見問題：
- 公式顯示成紅色原始碼 → KaTeX 不支援的語法，改寫
- 概念地圖太擠、文字被截斷、或拉成細長一條 → 減少節點、改方向（TD/LR）、拆成兩張
- 圖表標籤重疊或被裁切 → 調整參數重畫
- 寬表格或長公式超出頁面 → 拆開或改用 `aligned`
- 小抄超過預期頁數 → 刪減次要內容
- 學習講義大多是條列、幾乎沒有圖 → 回到 4a 補上動機、直觀解釋、圖與完整例題

確認無誤後交付 PDF，用一兩句話說明涵蓋範圍、每份文件的頁數或題數、有幾題無法程式驗算。不要在對話中重述文件內容。

## 檔案說明

- `scripts/render.mjs` — Markdown → 主題化 PDF（KaTeX 公式、Mermaid 圖、所有版面元件）
- `scripts/figures.py` — 教學圖表（分布、面積、直方圖、盒鬚圖、迴歸、文氏圖、線性變換、函數）
- `scripts/verify_helpers.py` — 驗算用的比較工具
- `assets/themes/*.css` — 三套主題與共用基礎樣式
- `references/markdown-format.md` — 撰寫語法 **寫 Markdown 前必讀**
- `references/organize-styles.md` — 概念分析、概念地圖、題型解題卡、Cornell、分層講義的寫法
- `references/figures.md` — 什麼內容畫什麼圖、怎麼畫
- `references/question-design.md` — 出題與解答撰寫指南（含語言規則）
- `references/verification.md` — 驗算流程與 SymPy 範本
- `references/reading-inputs.md` — 各類輸入資料（含 Google Drive）的讀取方式
